# 🌧️ Rain Noise Point Cloud Viewer

비 노이즈가 추가된 포인트클라우드를 원본과 비교해서 볼 수 있는 3D 뷰어입니다.

## 주요 기능

- **3가지 뷰 모드**: 원본, 비 노이즈 적용, 비교 모드
- **실시간 비 강도 조절**: 키보드로 비 강도를 실시간으로 조절
- **색상 구분**: 원본, 감쇠된 포인트, 비 노이즈 포인트를 다른 색상으로 표시
- **프레임 네비게이션**: 데이터셋의 모든 프레임을 순차적으로 탐색

## 파일 구조

```
rain_noise_utils.py      # 비 노이즈 시뮬레이션 클래스
rain_noise_viewer.py     # 메인 뷰어 애플리케이션
```

## 사용법

### 1. 실행
```bash
cd /home/ailab/git/Team_2/Seokjae/OpenPCDet
python rain_noise_viewer.py
```

### 2. 키보드 조작

#### 프레임 이동
- **D** 또는 **→**: 다음 프레임
- **A** 또는 **←**: 이전 프레임

#### 뷰 모드 전환
- **T**: 뷰 모드 순환
  - `Original`: 원본 포인트클라우드만 표시 (회색)
  - `Rain Noise`: 비 노이즈 적용된 포인트클라우드만 표시 (파란색)
  - `Comparison`: 원본과 비 노이즈를 동시에 표시

#### 비 강도 조절
- **↑**: 비 강도 증가 (+0.1)
- **↓**: 비 강도 감소 (-0.1)

#### 노이즈 범위 조절
- **+**: 노이즈 생성 반경 증가 (+0.5m)
- **-**: 노이즈 생성 반경 감소 (-0.5m)

#### 기타
- **F**: 현재 뷰포인트 저장
- **H**: 도움말 표시
- **Q**: 종료

### 3. 색상 구분 (Comparison 모드)
- **회색**: 원본 포인트
- **파란색**: 비로 인해 감쇠된 원본 포인트
- **빨간색**: 빗방울로 인한 노이즈 포인트
- **노란색 원**: 노이즈 생성 반경 가이드 (원점 기준)

## 비 노이즈 시뮬레이션 효과

### 1. 허위 반사점 생성 (원점 기준 반경 내)
- 빗방울로 인한 가짜 포인트 추가
- **원점(0,0) 기준 지정된 반경 내에서만** 노이즈 생성
- 기본 반경: 2.0m (실시간 조절 가능: 0.5~20.0m)
- 공간상 랜덤 위치에 낮은 intensity로 생성

### 2. 거리별 포인트 감쇠
- 멀리 있는 포인트일수록 더 많이 제거
- 비 강도에 비례한 감쇠율 적용

### 3. Intensity 감소
- 거리와 비 강도에 따른 intensity 값 감소
- 실제 LiDAR의 신호 감쇠 효과 시뮬레이션

## 설정 커스터마이징

`rain_noise_utils.py`의 `RainNoiseSimulator` 클래스에서 다음 파라미터들을 조정할 수 있습니다:

```python
default_config = {
    'RAIN_INTENSITY_RANGE': [0.3, 1.2],      # 비 강도 범위
    'BASE_NOISE_DENSITY': 0.005,             # 기본 노이즈 밀도
    'NOISE_RADIUS': 2.0,                     # 원점 기준 노이즈 생성 반경 (미터)
    'Z_BIAS_RANGE': [0.0, 6.0],              # 노이즈 Z 좌표 범위
    'RAIN_INTENSITY_VALUES': [0.02, 0.25],   # 빗방울 intensity 범위
    'MAX_ATTENUATION_DISTANCE': 50.0,        # 감쇠 적용 최대 거리
    'BASE_ATTENUATION_RATE': 0.08,           # 기본 감쇠율
    'MAX_ATTENUATION_PROB': 0.25,            # 최대 감쇠 확률
    'INTENSITY_REDUCTION_FACTOR': 0.15,      # Intensity 감소 계수
}
```

## 노이즈 반경 제어

- **기본 반경**: 2.0m (원점 기준)
- **조절 범위**: 0.5m ~ 20.0m
- **실시간 조절**: +/- 키로 0.5m 단위로 증감
- **시각적 가이드**: 노란색 원으로 반경 표시
